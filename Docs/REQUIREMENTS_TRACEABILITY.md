## 2. Non-Functional Requirements Traceability Matrix (NFR-001 to NFR-012)

| Req ID | NFR Category | Requirement Description | Implementation Enforcement | Verification Method |
| :--- | :--- | :--- | :--- | :--- |
| **NFR-001** | Privacy | Local processing only; zero outbound original content calls. | Localhost binding (`127.0.0.1`), local runtimes (Ollama/PyMuPDF/spaCy). | Network-disabled offline workflow test (`tests/test_offline.py`). |
| **NFR-002** | Security | Validate uploads by extension, MIME/signature, size, and parser outcome. | `core/security.py` file validator module with size checks & magic bytes. | Upload test suite testing invalid MIME types, oversized payloads, directory traversal filenames. |
| **NFR-003** | Integrity | Approved redactions applied to actual exported content. | `services/redaction_service.py` & `services/verification_service.py`. | Text extraction & string search comparison between approved set and exported artifact. |
| **NFR-004** | Usability | First-time user completes primary workflow with clear status. | React wizard UI, progress bars, degraded mode banners, guided workflow. | Usability test protocol (5 user walkthroughs) as defined in `08_Evaluation_and_Test_Plan.md`. |
| **NFR-005** | Performance | Report processing time and memory usage on evaluation machine. | Performance profiler middleware logging stage durations and peak RAM. | Benchmarking script recording execution metrics on target hardware. |
| **NFR-006** | Reliability | Failed detection, export or summary step shall not be represented as success. | Strict HTTP status codes, explicit error states (`FAILED`, `UNVERIFIED`). | Fault injection tests (simulated disk full, parser exception, model crash). |
| **NFR-007** | Maintainability | Detection methods modular and independently testable. | Plugin-style detector interfaces (`BaseDetector` class with common signature). | Unit tests testing regex, NER, and SLM detectors in complete isolation. |
| **NFR-008** | Portability | Run on documented Windows/Linux development setup. | Cross-platform Python standard library, standard paths (`pathlib.Path`). | Automated CI / test execution on both Windows PowerShell and Linux bash environments. |
| **NFR-009** | Accessibility | Visual indicators use text/icons in addition to color; keyboard navigation. | Accessible ARIA labels, semantic markup, high-contrast badges, keyboard shortcuts. | Accessibility audit with axe-core / automated React accessibility checks. |
| **NFR-010** | Observability | Logs avoid storing raw document text or PII by default. | Structured logger masking or omitting payload strings; SHA-256 for hashes. | Log audit test scanning generated application logs for presence of injected synthetic PII. |
| **NFR-011** | Reproducibility | Model name/version, ruleset version, and config recorded in runs. | Provenance metadata attached to session and evaluation artifacts. | Evaluation harness verifies output report records model tag, ruleset hash, and run timestamp. |
| **NFR-012** | Fail-safe | Failed export verification or summary privacy checks block output as unsafe. | Guard services fail closed (`is_safe: false`, download disabled). | Verification failure injection test ensuring download button is blocked and warning rendered. |
