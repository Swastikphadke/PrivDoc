| **NFR-009** | Accessibility | Visual indicators use text/icons in addition to color; keyboard navigation. | Accessible ARIA labels, semantic markup, high-contrast badges, keyboard shortcuts (`A`, `R`, `M`). | Frontend test suite (`frontend/src/hooks/useKeyboardShortcuts.test.js`). | **Verified (P4, P8)** |
